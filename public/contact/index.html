Common questions

More questions about MABS
How can I get help with MABS?

Use the contact form to describe your question or issue. Include relevant details so we can better understand your request.

Where can I report a technical problem?

Select Technical Issue and describe what happened, which feature you were using, and any error message you received. Do not include passwords, authentication tokens, or sensitive customer information.

How can I suggest a new feature?

Select Feature Request and explain the problem you want to solve or the improvement you would like to see.

How can I ask about billing?

Select Account or Billing and provide a brief description of your question. Never include complete payment card details or passwords.
